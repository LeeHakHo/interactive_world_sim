## 为什么要有这份文档(2026-07-19 教训)

`skelact_e2e_render` 那批 44 帧 gif 里,四个臂全是 NROB=100 的削弱模型,
但 gif 上没有任何地方写了这件事。用户看到"预测停住、画面糊",合理地怀疑是方法退化,
